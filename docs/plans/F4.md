# F4 — Voice activation

**Status:** proposed; gate open, waits for the owner's yes · **Milestone:** v1.5 · **Owner:** agent (T1 and T4 are the owner's: only a person can speak to Siri) · **Delivers:** FR9's Siri clause, deferred from v1.0 by `D15`

Learning level 5%, locked (`O2`).

## What the user gets

"Hey Siri, open the MonitorMenu switcher" opens the switcher. "Hey Siri, Monitor HDMI 1" switches the input. Today the macOS 27 Siri refuses both because it runs third-party actions only through Apple's App Schema domains and none fits a display (`docs/learnings/2026-10-23-siri-app-intents.md`). The app's side is done: six App Shortcuts with phrases, handed to the system at launch, running from the Shortcuts app and Spotlight. What v1.5 adds is a route Siri will take.

## Routes (D15), in the order to try

### F4-T1 — Siri Classic (owner, no code)

Owner: human · The setting is reported at System Settings › Screen Time › Content & Privacy › Siri › Allowed Siri Version; whether it exists on this Mac is unverified, which is why this is a task and not a claim. Then say "Open the MonitorMenu switcher" and "Switch my monitor to HDMI 1 with MonitorMenu". Checkpoint: the owner reports what Siri did. If it works, the route costs no code: the README gains three lines and v1.5 may stop here (`D19`).

### F4-T2 — Shipped shortcut files

Owner: agent · `scripts/make-shortcuts.sh` builds signed `.shortcut` files (plistlib and `shortcuts sign --mode anyone`, prototyped 2026-10-25) wrapping the URL scheme: "Monitor HDMI 1", "Monitor HDMI 2", "Monitor PiP Off", "Monitor Switcher". They ship in the bundle's Resources and an **Install Shortcuts…** menu item opens them for import (a user-visible change: `D20`, needs the owner's yes). Siri's "run <shortcut name>" path then applies. Checkpoint: the owner imports one and says "Hey Siri, Monitor Switcher"; the owner's 2026-10-25 test of this route ran once then stopped, so the checkpoint includes five tries over two days.

### F4-T3 — An App Schema domain, if Apple adds one

Owner: agent · Watch Apple's domain list at each macOS 27 point release. When a domain fits a display, conform the intents in `Sources/MonitorMenu/Voice.swift` with `@AssistantIntent(schema:)`. Checkpoint: Siri runs a phrase without naming a shortcut. Nothing is built until a domain exists.
